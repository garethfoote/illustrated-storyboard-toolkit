Quick reference

Keyboard controls

Selection and layers

Tab
Select the next object
Shift + Tab
Select the previous object
Option/Alt + ↑
Bring the selected character forward one layer
Option/Alt + ↓
Send the selected character backward one layer

Character movement

↑ ↓ ← →
Nudge the selected character by 5px
Shift + arrow
Nudge the selected character by 25px

Other shortcuts

F
Flip the selected object
Delete
Delete the selected object
Esc
Close an open menu or editor
